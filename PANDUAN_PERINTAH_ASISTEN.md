# 📖 BUKU PANDUAN PERINTAH ASISTEN KULIAH MA'AM
*Academic Virtual Office • Minimalist Aesthetic Edition*

> 💡 **Prinsip Utama:** Ma'am **BEBAS menggunakan bahasa santai sehari-hari**. Tidak perlu menghafal rumus kaku, karena asisten memahami kata kunci dan maksud kalimat Ma'am!

---

## 1. 👩‍💼 CANTIKA (Sekretaris Pribadi & Jadwal)

Cantika bertugas menyapa, memantau jadwal kuliah harian, dan mengatur pemindahan jam kuliah sementara.

| Apa yang Ingin Dilakukan | Contoh Perintah Bebas yang Bisa Diketik |
| :--- | :--- |
| **Tanya Jadwal Kuliah Hari Ini** | • *"Ada kuliah apa hari ini, Cantika?"*<br>• *"Jadwal kuliah sekarang apa aja?"*<br>• *"Hari ini ada kelas Zoom gak?"* |
| **Ubah Jam Kuliah Minggu Ini Saja** | • *"Cantika, ubah jam kuliah PBO hari Senin minggu ini jadi jam 8 malam"*<br>• *"Kuliah Cloud Computing diundur jadi jam 20:00"*<br>• *"PBO minggu ini geser ke jam 8 malam ya"* |
| **Pindah Hari Kuliah Minggu Ini** | • *"Cantika, kuliah IOT minggu ini pindah ke hari Sabtu jam 10 pagi"*<br>• *"Ganti jadwal Mobile Computing ke hari Rabu jam 7 malam"* |
| **Kembalikan ke Jadwal Normal** | • *"Cantika, kembalikan jadwal ke semula"*<br>• *"Reset jadwal kuliah normal"*<br>• *"Batalkan jadwal pengganti"* |
| **Cek Deadline Tugas** | • *"Cantika, ada deadline tugas apa minggu ini?"*<br>• *"Periksa tugas yang belum selesai"* |

---

## 2. 👩‍💼 REXHA (Dokumen & Converter Dua Arah: DOC ⇄ PDF)

Rexha bertugas mengurus berkas dokumen, format margin 4-3-3-3 standar kampus, dan konversi dua arah (**DOC ke PDF** & **PDF ke DOC/Word**).

| Apa yang Ingin Dilakukan | Contoh Perintah Bebas yang Bisa Diketik |
| :--- | :--- |
| **Konversi DOC ke PDF** (Siap Cetak / Kumpul) | • *"Rexha, tolong ubah dokumen tugas Word ini jadi PDF"*<br>• *"Format laporan praktikum ini siap cetak ke PDF"*<br>• *"Konversi file doc tugas ke pdf ya Rexha"* |
| **Konversi PDF ke DOC / Word** (Agar Bisa Diedit) | • *"Rexha, tolong konversi file PDF tugas ini ke format DOC Word agar bisa diedit"*<br>• *"Ubah berkas PDF materi ini jadi Word dong Rexha"*<br>• *"Ekstrak isi dokumen PDF ini ke file doc"* |
| **Buat Template Cover Makalah** | • *"Rexha, buatkan cover tugas resmi kampus"*<br>• *"Bikinin template cover makalah dong"*<br>• *"Siapkan halaman depan laporan kuliah"* |

---

## 3. 👨‍💻 HENDRY (Study Notes & Summary Specialist)

Hendry bertugas merangkum berkas materi kuliah (modul, slide PPT, dokumen PDF/Word) menjadi dokumen Microsoft Word (.doc) yang rapi, berisi intisari konsep dan cheat sheet / kisi-kisi tanya jawab untuk persiapan ujian Ma'am (bisa langsung dibuka & diedit di Microsoft Word).

| Apa yang Ingin Dilakukan | Contoh Perintah Bebas yang Bisa Diketik |
| :--- | :--- |
| **Drop File Materi & Rangkum** | • Drag & drop berkas materi ke Workstation Hendry di web, lalu klik **"Rangkum & Susun Study Notes"**.<br>• Atau drop file, lalu ketik: *"Hendry, tolong rangkum file modul ini ya"* |
| **Rangkum Topik Kuliah Tertentu** | • *"Hendry, tolong rangkum materi Cloud Computing ini dan buat kisi-kisi ujiannya"*<br>• *"Ringkas konsep penting tentang Pemrograman Berorientasi Objek"*<br>• *"Hendry, buatkan intisari materi Cyber Security"* |
| **Susun Cheat Sheet & Kisi-Kisi Ujian** | • *"Hendry, buatkan cheat sheet dan kisi-kisi tanya jawab untuk ujian PBO"*<br>• *"Susun poin-poin hafalan penting sebelum kuis besok"* |

## 💡 KATA KUNCI PENTING (Biar Pasti Dipahami Asisten)
Cukup pastikan di kalimat Ma'am ada salah satu kata kunci ini:
* Untuk **Cantika**: `jadwal`, `kuliah`, `ubah jam [nama matkul]`, `tugas`, `reset`.
* Untuk **Rexha**: `pdf`, `doc`, `word`, `konversi`, `ekstrak`, `cover`, `template`.
* Untuk **Hendry**: `rangkum`, `ringkas`, `materi`, `cheat sheet`, `catatan`, `kisi-kisi`, `ujian`, `modul`, `slide`.
