1. 📌 Intisari Konsep & Poin-Poin Kunci

  • Model Layanan: IaaS (Infrastructure as a Service), PaaS (Platform as a Service), SaaS (Software as a Service).
  • Deployment Model: Public Cloud (AWS, GCP, Azure), Private Cloud (Internal Organisasi), Hybrid Cloud, Community Cloud.
  • Karakteristik Esensial: On-demand self-service, broad network access, resource pooling, rapid elasticity, measured service.
  • Virtualisasi & Kontainer: Perbedaan mendasar antara Virtual Machine (Hypervisor-based) vs Container (Docker/Kubernetes lightweight engine).

2. 🎯 Kisi-Kisi Tanya Jawab Persiapan Ujian (Exam Takeaways)

Q1: Kapan organisasi harus memilih PaaS dibanding IaaS?
Q2: Jelaskan prinsip Shared Responsibility Model dalam keamanan Cloud!
Q3: Keuntungan arsitektur Microservices di atas container.
